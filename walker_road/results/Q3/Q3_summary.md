# Q3 – Can OMA at service level say anything about Walker Road at ULS?

Generated by `q3_run.py`. Limit states in λ = CL-625 trucks per lane (both lanes): SLS = 1.00, 75% ULS = 1.43, ULS = 1.91, beyond ULS = 3.00. ULS = 1.70 × 1.25 × 0.90 (S6-19 load factor, dynamic allowance, two-lane factor).
Prestress losses (S6-19 8.7.4): 31.9 %. Bearings: linear springs; uplift, slip and locking are checked, not assumed. Changes are stiffness-only (test-load mass removed, see step 4).

|---|---|---|---|---|---|---|---|

| 75% ULS | 1.43 | 0 | 100 % | 1.00 | 0.02 | 1.0 / 225 | opens 0.7 mm |
| ULS | 1.91 | 7 | 98 % | 1.00 | 0.02 | 1.3 / 225 | opens 0.9 mm |
| beyond ULS | 3.00 | 76 | 68 % | 1.00 | 0.03 | 2.2 / 225 | opens 1.5 mm |

First girder decompression at λ = 1.13, first cracking at λ = 1.87 (interior girders G4/G5).
**Answer:** yes, but only the girders change: they start to crack right at ULS. The bearings do not lift off, slip or lock up to the flexural resistance, so the supports stay as they are.

|---|---|---|---|---|---|---|---|---|

| 75% ULS | -0.02 % | -0.25 % | -1.83 % | 1.000 | 1.000 | 1.000 | -0.00 % | 1.000 |
| ULS | -0.05 % | -0.28 % | -2.02 % | 1.000 | 1.000 | 1.000 | -0.00 % | 1.000 |
| beyond ULS | -5.50 % | -3.00 % | -2.97 % | 0.976 | 0.984 | 1.000 | -0.51 % | 1.000 |

Detection limits: |Δf| ≥ 0.5 %; MAC below the measured scatter (M1 0.998, M2 0.997, M3 0.999).
**Answer:** up to ULS, only M3 (first transverse-bending mode) changes detectably, by 1–2 %: that is local deck cracking under the wheels, which in reality has probably already happened under normal traffic. Girder cracking at ULS is too small to see (M1, M2 and all mode shapes stay within the detection limits). Beyond ULS, M1 drops about 5 % with the load on and the shapes change beyond the measured scatter; after unloading the prestress closes the cracks and the change is mostly gone.

## Step 3 – Can OMA tell what the supports are doing?

| south pads stiffer x2 | +0.7 % | 0.990 | 0.00/0.00 | 0.00/0.00 | 1.0/2.0 | 1.20/1.47 | -1.4 % |

**Answer:** a change in support fixity is very visible to OMA (frequencies +20 to +40 %, MAC down to about 0.88), much more than girder cracking. Calibration finds which end changed, but not how much: it over-estimates the fixity and compensates with a girder-modulus drop that is not real. Pad vertical stiffness is hard to identify, and cracking beyond ULS partly ends up in the pad stiffness. Support and girder stiffness are therefore not cleanly separable with 9 accelerometers.

## Step 3b – Bilinear rotational stiffness at the supports (k1 → k2 = 0.75 k1)

Threshold = first girder cracking, λ = 1.87. The physical alternative, the pad's back edge unloading under end rotation, is never reached at Walker Road.

| Supports (k1) | M1 Δf just above threshold, without rule | with rule | extra from the rule | lowest MAC with rule |
|---|---|---|---|---|
| ends as they are (pad only) | -0.03 % | -0.06 % | -0.03 % | 1.000 |
| both ends half-fixed | -0.03 % | -3.84 % | -3.81 % | 1.000 |
| north end half-fixed | -0.04 % | -2.26 % | -2.23 % | 1.000 |

**Answer:** with the ends as they are (practically pinned) the rule changes nothing (k1 is already tiny). If the ends were partly fixed, the 25 % drop in rotational stiffness lowers M1 by about 2–4 % in one step at the threshold – a detectable jump, larger than the girder cracking at ULS.

## Step 3c – Range of support rules (sensitivity)

All combinations of k2/k1 = 0.5, 0.6, 0.75, 0.9, threshold at SLS / 75 % ULS / ULS, and softening at both ends, the north end or the south end (36 rules per k1), for three starting supports.

| k1 (starting supports) | M1 Δf at SLS | M1 Δf at 75% ULS | M1 Δf at ULS | M1 Δf at beyond ULS | lowest MAC (M1–M3), all |
|---|---|---|---|---|---|
| pad only (as built) | -0.1 … -0.0 % | -0.1 … -0.0 % | -0.1 … -0.1 % | -5.6 … -5.5 % | 0.975 |
| quarter-fixed | -7.0 … -0.0 % | -7.0 … -0.0 % | -7.0 … -0.6 % | -11.2 … -4.7 % | 0.936 |
| half-fixed | -8.7 … -0.0 % | -8.7 … -0.0 % | -8.8 … -0.8 % | -12.3 … -4.2 % | 0.945 |

**Answer:** with the supports as built (pad only), no rule makes a difference – the ends are already practically pinned. If the ends carry some fixity (a quarter to a half), a softening rule can lower M1 by up to 7–9 % already at SLS/ULS (depending on α and which end), i.e. far more than girder cracking. The mode shapes at the 9 accelerometers change much less (lowest MAC 0.993 for quarter-fixed, 0.998 for half-fixed ends, up to ULS), which is only just beyond the measured MAC scatter of M1 (0.998). Support softening is therefore mainly a frequency signal, with a small mode-shape signal when one end softens more than the other.

## Step 4 – Removing the effect of the test load

OMA measured with the test load on the bridge sees the damage AND the added mass. Corrections use only the known load (mass, position) and the calibrated undamaged model.

| Limit state | M1 true (no mass) | M1 measured with load | error after Rayleigh | error after model ratio | MAC M1–M3 no correction | MAC perturbation | MAC model subtraction |
|---|---|---|---|---|---|---|---|
| SLS | -0.02 % | -11.7 % | -0.49 % | -0.03 % | 0.958 | 0.994 | 1.000 |
| 75% ULS | -0.02 % | -15.8 % | -0.83 % | -0.06 % | 0.933 | 0.979 | 1.000 |
| ULS | -0.05 % | -19.8 % | -1.20 % | -0.09 % | 0.907 | 0.947 | 1.000 |
| beyond ULS | -5.50 % | -31.4 % | -2.27 % | -0.45 % | 0.859 | 0.814 | 0.988 |

**Answer:** the test-load mass hides the damage (M1 about −12 % per truck pair, against −0.05 % from cracking at ULS). Dividing out the mass effect predicted by the calibrated model recovers the true frequencies within 0.5 % and the true mode shapes (MAC ≥ 0.98) up to beyond ULS. The simpler Rayleigh correction with mass-normalised shapes works for light loads (error < 0.5 % up to about one truck per lane) but grows to 1–2.5 % for heavy loads, because the heavy mass also changes the shapes.
